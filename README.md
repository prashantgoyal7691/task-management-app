📝 Task Management Application

A full-stack Task Management Web Application built using React, Node.js, Express, and MongoDB.
The application allows users to manage tasks efficiently with authentication, task lifecycle tracking, and history management.

⸻

🚀 Features

🔐 Authentication
	•	User Registration & Login
	•	JWT-based Authentication
	•	Protected Routes
	•	Secure Logout

📋 Task Management
	•	Create new tasks
	•	Organize tasks into:
	•	Todo
	•	In Progress
	•	Move tasks between columns
	•	Mark tasks as Completed
	•	Abandon tasks when needed
	•	Delete tasks

🕒 Task History
	•	View Completed tasks
	•	View Abandoned tasks
	•	History persists even after refresh
	•	Clean separation between active tasks and history

🎨 User Experience
	•	Clean and responsive UI
	•	Personalized greeting using user’s first name
	•	Smooth navigation between Dashboard and History
	•	Modal-based task creation

⸻

🛠 Tech Stack

Frontend
	•	React
	•	React Router
	•	Axios
	•	Tailwind CSS

Backend
	•	Node.js
	•	Express.js
	•	MongoDB (Atlas)
	•	Mongoose
	•	JWT (JSON Web Tokens)
